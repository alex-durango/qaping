# Contributing to Qaping

Bug reports, documentation corrections, and ideas from game developers help
shape Qaping. [Open an issue](https://github.com/alex-durango/qaping/issues/new/choose)
to share one, or ask a question in [Discord](https://discord.gg/pUKzftBUTY).

## Reporting a bug

Include what you expected, what happened, and the steps to reproduce it.
For setup or CLI problems, include your operating system, coding agent,
the output of `qaping version`, and the command that failed.
For a playtest problem, include the round ID and game platform.

Remove tokens, account details, and private build links from logs before
posting them. Screenshots and short recordings are helpful when they show
the problem clearly.

## Documentation and feature requests

Link the page or section you want to improve and suggest the wording, or
describe the game-development task you are trying to complete. Concrete
examples help us understand the change.

This repository contains Qaping's public documentation. It is synced from the
documentation maintained with the CLI, so maintainers apply accepted changes
there and publish them here. You can use an issue or pull request to propose
a correction.
